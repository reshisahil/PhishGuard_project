Features Analyzed

PhishGuard evaluates critical indicators commonly altered in phishing links and social engineering designs.

URL Length

Phishing attempts often utilize extremely long URLs to hide suspicious domain subfolders or mimic legitimate structures.

Special Characters

Frequent usage of special characters like @, ?, =, and - can indicate redirect paths or obfuscation tactics.

Subdomains

Attackers nest multiple subdomains (e.g. login.paypal.com.secure.net) to trick users into believing the link is genuine.

IP Instead of Domain

Using raw IP addresses (e.g. http://192.168.1.1/login) bypassing Domain Name System (DNS) naming is highly indicative of malicious setups.

HTTPS Security

While HTTPS encrypts communications, modern phishing sites frequently use free SSL certificates to build a false sense of security.

Suspicious Patterns

PhishGuard scans for structural markers and keyword patterns typical of urgency-based credentials harvesting schemes.

About SYNEXUS PhishGuard

PhishGuard is an educational cybersecurity MVP designed to analyze measurable URL characteristics and provide an understandable, risk-oriented phishing prediction. It operates as an on-device heuristic engine to showcase how structural URL patterns can be mapped to machine learning features.

By checking parameters like subdomains, entropy indicators, SSL setups, and URL length, PhishGuard mimics the feature-extraction pipeline utilized in real-world ML spam and phishing detectors.

Disclaimer

PhishGuard provides risk-oriented predictions and cannot guarantee that a URL is safe or malicious. It is an educational tool and should not replace antivirus software or professional threat intelligence.
