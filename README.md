# PhishGuard_project

# Project Summary

SYNEXUS PhishGuard is an ML-based phishing URL detection system designed to identify URLs that exhibit characteristics commonly associated with phishing attacks. The system extracts relevant features from a URL, processes them through a machine learning model, and provides a risk-oriented prediction such as Likely Legitimate or Potentially Phishing.

The project is being developed as a collaborative initiative under the **SYNEXUS Tech Club Cybersecurity Domain**, combining cybersecurity, machine learning, web development, and cloud technologies.

## Key Features
- 🔗 URL feature extraction and analysis
- 🤖 Machine learning-based classification
- 🛡️ Phishing risk assessment**
- 📊 Explainable indicators behind predictions
- 🌐 Web-based interface for URL analysis
- 📈 Model evaluation and performance comparison

## Tech Stack

**Python • Pandas • NumPy • Scikit-learn • Flask/FastAPI • HTML • CSS • JavaScript • Git/GitHub**

## Disclaimer

PhishGuard is an educational/research project. Its predictions are not guaranteed to determine whether a website is safe or malicious and should not replace professional threat-intelligence or security solutions.
